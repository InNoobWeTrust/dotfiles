# Portfolio construction (multi-asset)

## Jobs of money (assign before weights)

| Job | Typical sleeves | Failure mode if mislabeled |
|---|---|---|
| **Liquidity** | Cash, short gov, quality MM | Using HY/crypto as emergency fund |
| **Ballast / income** | IG bonds, diversified bond funds, some dividend quality | Confusing HY single-name with ballast |
| **Growth** | Equity funds, diversified stocks | Overconcentration in one name/sector |
| **Hedge / insurance** | Gold, sometimes FX, tail hedges | Expecting hedge to “yield like credit” |
| **Speculation** | Single names, crypto alts, concentrated themes | Sizing like core |

## Construction steps

1. **Cash floor** from life liquidity (months of expenses + near liabilities).  
2. **Hedge budget** if investor fears debasement/geopolitics (gold etc.).  
3. **Growth engine** to meet long-horizon goals (risk budget from max drawdown tolerance).  
4. **Income/ballast** to dampen path (not maximize yield).  
5. **Satellites** (single-name credit, themes, crypto) only from **risk budget leftover**, each ≤ max pain on wipeout path.  
6. **Check stress correlation** — sum of satellites that fail together.  
7. **Rebalance bands** (e.g. ±20% relative of target sleeve) + tax awareness.  
8. **Capital priority when constrained:** cash floor → hedge (if thesis requires) → growth → satellites last.

## Concentration guides (defaults — override with rails)

| Limit idea | Default instinct |
|---|---|
| Single unsecured credit issuer | ≤ max pain (often << 5–10% NW) |
| Single stock | Small unless intentional concentration + pain OK |
| Single sector | Watch hidden overlap across funds |
| Illiquid total | Only capital that can be locked |
| Speculative crypto alts | Small fraction of crypto sleeve; sleeve itself capped by pain |

## Scenario set (minimum)

| Scenario | Ask |
|---|---|
| Base | Plan path |
| Rates/inflation flip | Who loses duration / real yield |
| Risk-off | Equity/crypto/HY drawdown together? |
| Idiosyncratic issuer fail | Satellite wipeout ≤ pain? |
| FX gap (if relevant) | Local nominal wealth vs hard lens |

## Barbell patterns (examples, not prescriptions)

- Cash + equity index (simple)  
- Cash + gold + diversified equity (debasement-aware)  
- Bond fund ballast + equity growth (classical)  
- Small HY/credit satellite **outside** cash (carry, eyes open)  
- Avoid: “all carry, no hedge” when investor narrative is collapse; avoid “all gold, no growth” if horizon is decades and goals need compounding  

## Output

- Target weights or bands by sleeve  
- Satellite list with ceilings  
- What to fund first if capital incomplete  
- Rebalance / review calendar  
- Explicit non-goals (e.g. “not trying to beat gold with credit”)
