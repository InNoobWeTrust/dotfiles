# Asset class: Public equity

## Job

Long-horizon growth / ownership residual claim. Not a cash substitute.

## Diligence checklist (single name)

- [ ] Business model & unit economics  
- [ ] Competitive position / disruption risk  
- [ ] Financials: growth, margins, leverage, FCF, dilution  
- [ ] Valuation vs history and peers (multiple methods if possible)  
- [ ] Governance, related parties, listing quality  
- [ ] Liquidity (ADV vs position size)  
- [ ] Catalyst vs thesis time match  
- [ ] Downside scenarios (earnings shock, multiple compression)  

## Diligence checklist (index / broad beta)

- [ ] Index rules, country/sector concentration  
- [ ] Total expense if via fund/ETF  
- [ ] Tracking difference  
- [ ] Currency exposure  

## Sizing

- Single name: left-tail can approach −50% to −100%; size ≤ pain  
- Core equity sleeve: sized to **max drawdown tolerance** over horizon  
- Avoid duplicating employer sector  

## Regime notes

- Risk-off / recession: beta hurts; quality/defensives relative  
- Easy liquidity: multiples expand — don’t extrapolate forever  
- Local FX: equity may partially hedge via exporters; not automatic  

## Anti-patterns

- Momentum chase without thesis  
- “Cheap” on one multiple with broken balance sheet  
- Concentrated yolo as “long-term investing” without pain budget
