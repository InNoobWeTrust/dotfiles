# Anti-patterns — Investment Assessment

| Temptation | Why wrong | Correct path |
|---|---|---|
| Return shopping across unlike assets | Different jobs and tails | Assign roles first |
| Bond-only checklist on every asset | Misses equity/crypto/gold specifics | Load class module |
| Ignore regime | Static allocation in changing weather | Explicit base + stress regime |
| One headline → 100% shift | Whipsaw, no process | Bands + triggers |
| Label speculation as cash/ballast | Sizing error | Honest job tags |
| Yield without left tail | Blow-ups | Size to wipeout/pain |
| Fake IRR race (bond vs gold vs BTC) | Incomparable paths | Role + scenario matrix |
| Skip fees/tax | False “edge” | Net everything |
| Average down without re-underwrite | Good money after bad | Thesis reset or accept loss |
| Home bias unexamined | Concentration | State and stress it |
| Employer + sector double dip | Income + book same shock | Cap combined exposure |
| Liquidity fantasy | Can’t exit stress | HTM plan for illiquids |
| Macro excuses bad micro | Broken product still broken | Terms and quality first |
| Micro stock-pick without cycle | Value traps in bad regimes | Regime filter then micro |
| Overfit backtest / sold-out FOMO | Selection bias | Process > narrative |
| Informal workarounds (pools, side deals) | Legal/title risk | Licensed channels only |
| Guaranteed-return language | False safety | Refuse or reframe |
| No disclaimer | Misuse risk | Always decision-support only |
| Fabricated data | Liability | Sources or unknown |
| Satellite stack same factor | Hidden concentration | Stress co-failure |
| Cut hedge to buy carry under collapse fear | Inverted priorities | Cash/hedge before satellite |
| Analysis paralysis forever | No decision | Time-box; decision card with triggers |
