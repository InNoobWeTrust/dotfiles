# Visual QA Checklist

## Intent

- [ ] The illustration communicates one primary thesis; if it is a comparison panel, the key contrast is still obvious.
- [ ] The first thing the eye sees is the intended focal point.
- [ ] Decorative elements do not compete with the message.

## Layout

- [ ] Grouping, sequence, and hierarchy are obvious.
- [ ] Alignment and spacing feel deliberate and consistent.
- [ ] There is enough white space for the composition to breathe.
- [ ] Callouts and labels do not collide with shapes or each other.

## Readability

- [ ] Text is legible at final embed size.
- [ ] Color contrast is sufficient.
- [ ] Icons and metaphors are understandable without long explanation.
- [ ] If the piece needs paragraph-length explanation, simplify the visual.

## Correctness

- [ ] Claims, numbers, labels, and source cues are accurate.
- [ ] Relative emphasis matches actual importance.
- [ ] Upstream `[UNKNOWN]`, target-state, or caveat markers that materially affect meaning remain visible after illustration/export.
- [ ] If evidence strength is limited, the illustration does not overstate certainty.
