# Layout Methodologies

Choose the structure before drawing.

## Common layouts

| Pattern | Best for | Rules |
|---|---|---|
| Linear Infographic | Step-by-step explanation | Clear top-to-bottom or left-to-right progression |
| Hub-and-spoke | One central concept with supporting factors | Keep the center dominant and spokes balanced |
| Comparison panel | Before/after, option A vs B | Mirror structure so differences are easy to scan |
| Annotated hero | One main visual with callouts | Keep annotations outside the focal object when possible |
| Academic multi-panel | Figure with sub-panels A/B/C | Shared visual language, consistent axes / legends / captions |
| Poster layout | Big headline + strong focal region + supporting evidence | Headline first, then focal image, then proof/details |

## Quick selection map

- Sequential story or process -> Linear Infographic
- One core concept with supporting factors -> Hub-and-spoke
- Before/after or option comparison -> Comparison panel
- One central object with annotations -> Annotated hero
- Coordinated evidence panels for paper/article -> Academic multi-panel
- Presentation slide or poster with one bold message -> Poster layout

## Selection rules

1. Decide what the viewer must notice first.
2. Group related information physically.
3. Use white space to separate concepts.
4. Prefer one strong composition over many weak mini-elements.
5. If the story is sequential, make the flow unmistakable.
