# Audience Visual Budget

Match the amount and density of visuals to the audience.

| Audience | Default | Notes |
|---|---|---|
| `exec` | 1-2 hero visuals | Big Idea first; every visual must earn its space |
| `analyst` | up to 5 visuals | More evidence is acceptable if each chart answers a distinct question |
| `ops` | 0-2 visuals | Prefer exception-oriented bars, bullets, or tables |
| `customer` | 0-1 visual | Keep language and structure simple |
| mixed / unknown | 1-3 visuals | Favor clarity over completeness |

## Rules

1. One visual should support one material claim.
2. More visuals do not mean more insight.
3. When the visual budget is exhausted, summarize secondary evidence in text or tables.
4. If a richer multi-panel composition would communicate better, route to `illustration-craft`.
