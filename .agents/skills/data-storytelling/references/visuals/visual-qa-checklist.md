# Visual QA Checklist

Run this checklist after creating any chart.

## Correctness

- [ ] The chart type matches the claim.
- [ ] The baseline, comparator, and units are visible or obvious.
- [ ] Axis direction and scale support honest interpretation.
- [ ] Bars start at zero unless explicitly justified otherwise.
- [ ] Legends, labels, and annotations match the data shown.
- [ ] The visual does not imply stronger certainty than the approved `claim_ceiling`.

## Readability

- [ ] No text overlaps marks, lines, or other text.
- [ ] Labels are legible at the intended final size.
- [ ] Important elements stand out without using too many accent colors.
- [ ] Category counts, series counts, and annotation density remain readable.
- [ ] The chart can be understood in a few seconds.

## Narrative fit

- [ ] The title or caption states the takeaway.
- [ ] The visual is placed near the claim it supports.
- [ ] If the visual adds little beyond text, remove it.
- [ ] If the message is conceptual rather than chart-shaped, escalate to `illustration-craft`.
