# Scientific Research Proposal Template

Use this template to format proposals generated by the scientific research path of brainstorming.

The headings define content structure. Saved human-readable proposals apply a document format and presentation capability: Typst + PDF by default; if unavailable, use plain Markdown with clear section headings. Required submission templates and executable notebooks retain their native formats.

---

# [Project Title: Mechanistic & Actionable]

## 1. Executive Summary & Core Gap
- **Central Question:** What fundamental question does this solve?
- **The Gap:** Why do current tools/papers fail to address it?
- **The "What-If" Vision:** The transformative outcome if this hypothesis holds.

## 2. Mechanistic Hypothesis & Biological/Physical Grounding
- **Input Entities & Modalities:** Exact coordinate systems, sequence representations, or measurement vectors.
- **Causal Mechanism:** The proposed biophysical/biochemical chain of events.
- **Transfer Link:** Source principle → intervention → causal mechanism → user-relevant outcome → falsifier; distinguish inspected facts from assumptions. For non-biological research use its actual entities and outcomes, not forced assay language.
- **Literature Anchors:** Real published studies supporting the biological plausibility.

## 3. In Silico / Experimental Protocol
- **Model / Architecture:** Specific checkpoints (e.g. `NTv3_650M_pos`) and adaptations (custom heads, loss functions).
- **Data Pipeline:** How lab data (e.g., fragments, BigWigs, matrices) is preprocessed and split.
- **Compute Budget & Runtime:** Hardware target (e.g. Colab A100, Marimo MoLab B200) and expected execution time.

## 4. Confidence, Interpretability & Statistical Validation
- **Feature Attribution:** Saliency maps, integrated gradients, or in-silico saturation mutagenesis (ISM).
- **Statistical Tests:** Permutation baselines, p-values, FDR corrections, Pearson/Spearman correlations.
- **Wet-Lab / Experimental Corroboration:** How computational predictions map to measurable lab assays (e.g. qPCR, flow cytometry, CRISPR).

## 5. Negative Controls & Kill Criteria
- **Disconfirming Observations:** What specific observation proves this proposal WRONG?
- **Kill-Switches:** Quantitative thresholds for abandoning or pivoting the project.
- **Relevance Check:** Would success address the original question rather than merely improve a leaf mechanism/proxy? Explain the necessity of any dominant implementation detail and test a simpler alternative where plausible.
